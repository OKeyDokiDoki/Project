# 开发路线

## Phase 1：基础闭环

- 手机号或微信登录
- 用户照片上传
- 商品库和服装图片
- 单人 2D 虚拟试穿
- 历史记录与收藏
- 基础尺码推荐

## Phase 2：体验增强

- 人体尺寸与体型识别
- 场景化智能搭配
- 多款并排对比
- 拍照、短视频与海报分享
- 购物车、订单和库存联动

## Phase 3：门店与实时能力

- 大屏镜面端
- 摄像头实时采集
- 动作跟随、手势与语音控制
- 设备远程管理
- 门店数据看板

## Phase 4：高级试穿

- 3D 服装资产管线
- 360 度展示与面料物理效果
- 多人云试穿
- 直播实时试穿
