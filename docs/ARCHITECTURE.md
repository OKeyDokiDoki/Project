# 架构说明

## 领域模块

1. 身份与会员：微信、手机号、会员同步、历史与收藏。
2. 人体档案：关键点、尺寸、体型、肤色与用户微调。
3. 虚拟试穿：图片或视频输入、服装资产、生成任务、结果管理。
4. 商品与尺码：商品、SKU、库存、品牌尺码表、合身度推荐。
5. 搭配推荐：场景、风格、颜色规则和个性化排序。
6. 交易链路：购物车、订单、门店提货与配送。
7. 门店设备：镜面终端、手势与语音输入、远程设备管理。
8. 数据分析：试穿热度、转化、偏好、客流与热销排行。

## 推荐技术边界

- Web 与小程序负责采集、交互和结果展示。
- Vue 3 用户端负责试穿交互，后续管理端可复用同一组件与类型体系。
- Spring Boot API 服务负责身份、商品、任务编排和业务数据。
- AI 推理服务独立部署，异步处理人体分析与试穿生成。
- Redis 用于任务队列和短期状态，PostgreSQL 保存核心业务数据。
- 对象存储保存用户输入、服装资产、3D 模型和生成结果。

## 数据安全

人体照片、视频与身体尺寸属于敏感数据。正式开发时需要实现明确授权、最小化采集、加密存储、访问审计、数据保留期限和用户删除机制。
